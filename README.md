# WaterCare AI

SDG 6: Clean Water and Sanitation AI Agent Project.

- AI Chatbot for water-related queries
- User Dashboard
- Admin Dashboard
- Client Dashboard
- Complaint Tracking System

- React / TypeScript
- Vite
- Supabase (Database & Auth)
- Tailwind CSS

This project helps users:
- Report water issues
- Get safety tips
- Learn about water conservation
- Interact with an AI assistant
